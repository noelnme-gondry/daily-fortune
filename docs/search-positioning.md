# 오행 운세의 검색 포지셔닝

2026-10-14 Gondry 요청: **무료가 핵심 강점**이다. 기존 브랜드 이름은 유지하고, 회원가입 없이 점수와 상세 결과까지 무료로 제공한다는 사실을 먼저 알린다. 제목·첫 화면·설명·FAQ를 수정할 때 이 기준을 유지한다.

무료 범위와 공통 답변의 원본은 `src/content/pages.js`의 `FREE_ACCESS`, `FREE_FAQ`이다. 도구 화면과 FAQ, 가격 구조화 데이터, AI용 요약이 이를 함께 사용한다. 검색 결과용 제목·설명은 페이지별 검색 의도에 맞추며, 같은 단어를 무리하게 반복하지 않는다.

| 검색 의도 | 주요 페이지 | 제공 내용 |
| --- | --- | --- |
| 무료 사주, 무료 운세, 사주, 운세 | `/` | 무료 이용 범위와 도구별 진입점 |
| 무료 사주풀이, 평생 운세 | `/lifetime/` | 원국 풀이와 대운 흐름 |
| 오늘의 운세, 무료 오늘의 운세 | `/today/` | 개인 사주 기반 일별 결과 |
| 이달의 운세, 무료 월간 운세 | `/month/` | 월간 흐름과 날짜별 달력 |
| 무료 신년운세, 해당 연도 운세 | `/year/`, `/year/{현재 연도}/`, `/year/{다음 연도}/` | 연간 총운과 월별 해설 |
| 무료 궁합, 무료 만세력 | `/compatibility/`, `/manseryeok/` | 두 사람의 궁합, 사주 원국 계산 |
| 무료 토정비결, 해당 연도 토정비결 | `/tojeong/`(올해, `/tojeong/{현재 연도}/`는 301), `/tojeong/{다음 연도}/` | 144괘 총운과 음력 12개월 무료 해설 |
| 토정비결과 사주 차이 | `/about/#tojeong` | 작괘와 사주 계산의 차이 안내 |

토정비결은 생년월일로 144괘를 구하는 별도 계산기로 제공한다. 사주 신년운세를 ‘무료 토정비결’로 이름만 바꾸지 않는다. 총운과 12개월 해설 모두 무료이며, 계산법·해설의 출처와 판본 기준은 `docs/tojeong.md`와 화면에 공개한다.

SEO는 고유한 제목·설명, 본문, 내부 링크와 크롤링 가능한 페이지를 기본으로 한다. AEO/GEO에서는 질문에 바로 답하는 설명과 FAQ, 계산 근거와 출처가 중요하다. JSON-LD는 화면 내용과 일치시킨다. `llms.txt`는 보조 요약이며 노출·인용을 보장하지 않는다. Google은 AI 검색에 별도 AI 파일이나 특수 구조화 데이터를 요구하지 않는다.

현재 키워드별 검색 노출·클릭·순위와 AI 답변 인용 실적은 미확인이다. 배포 후 Search Console·네이버 서치어드바이저의 실제 데이터로 판단한다. 코드에 문구를 넣었다는 사실을 검색 유입 성과로 보고하지 않는다.
