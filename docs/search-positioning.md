# make your own day 검색 포지셔닝

2026-10-14 Gondry 요청: **무료가 핵심 강점**이다. 기존 브랜드 이름은 유지하고, 회원가입 없이 점수와 상세 결과까지 무료로 제공한다는 사실을 먼저 알린다. 제목·첫 화면·설명·FAQ를 수정할 때 이 기준을 유지한다.

무료 범위와 공통 답변의 원본은 `src/content/pages.js`의 `FREE_ACCESS`, `FREE_FAQ`이다. 도구 화면과 FAQ, 가격 구조화 데이터, AI용 요약이 이를 함께 사용한다. 검색 결과용 제목·설명은 페이지별 검색 의도에 맞추며, 같은 단어를 무리하게 반복하지 않는다.

SEO는 고유한 제목·설명, 본문, 내부 링크와 크롤링 가능한 페이지를 기본으로 한다. AEO/GEO에서는 질문에 바로 답하는 설명과 FAQ, 계산 근거와 출처가 중요하다. JSON-LD는 화면 내용과 일치시킨다. `llms.txt`는 보조 요약이며 노출·인용을 보장하지 않는다. Google은 AI 검색에 별도 AI 파일이나 특수 구조화 데이터를 요구하지 않는다.

2026-10-18 확인한 Google 한국 웹 검색 실적은 실제 제공 기간 10월 12~15일에 37노출·1클릭·평균 게재순위 31.05다. 노출이 있는 날짜는 14~15일 두 날짜뿐이고, 검색어별 표본도 대부분 1~2회다. AI 답변 인용 실적은 미확인이며, 코드에 문구를 넣었다는 사실을 검색 유입 성과로 보고하지 않는다.

2026-10-15 핵심 페이지의 색인 검사, 공개 계산 예시, 한국 사용자 측정 계약은 [검색 개선 작업 기록](search-audit-2026-10-15/README.md)에 정리했다. 검색 성과와 URL 색인은 구분한다. 공개 예시는 `src/site/public-examples.js`, 연간 기능 비교는 `src/site/year-guide.js`, 시간 미상 설명은 `src/content/calculation-notes.js`에서 관리한다.

## 외부 프로필용 한국어 소개문 초안

make your own day(메이크 유어 오운 데이)는 회원가입 없이 상세 결과까지 무료로 이용하는 한국어 사주·운세 서비스입니다. 생년월일시로 사주 원국과 오늘·월간·신년·평생 운세, 궁합을 계산하며, 만세력과 별도 작괘 방식의 토정비결도 제공합니다. 출생 정보는 브라우저에서 처리하고 기기 저장은 선택할 수 있습니다. 계산 기준과 시간 미상 처리, 해석의 한계를 공개하며, 운세 점수를 미래의 성공 확률이나 예측 정확도로 제시하지 않습니다.

공식 주소: https://makeyourownday-fortune.com/ . 위 소개문은 게시 전 초안이다. 운영자 개인의 경력·자격·법적 사업자명은 확인하지 않았으며 새로 추가하지 않는다.

참고: [Google 제목 작성 지침](https://developers.google.com/search/docs/appearance/title-link), [Google AI 검색 지침](https://developers.google.com/search/docs/appearance/ai-features), [무료 접근 여부 구조화 데이터](https://schema.org/isAccessibleForFree).

## 2026-10-17 검색 결과 노출 정리

- 도구 페이지 제목에 `무료`를, 설명과 첫 문단 앞쪽에 `회원가입 없이 무료`를 넣었다. Google 스니펫은 메타 설명 대신 첫 문단(`lead`)을 쓰는 경우가 많아 두 곳 모두 고쳤다.
- 검색 결과의 사이트 이름(도메인으로 표시)과 `運` 파비콘, 제목 끝의 `오행 운세`는 리브랜딩(10-14) 전 크롤링 결과다. 사이트 이름은 홈의 `WebSite` 구조화 데이터·`og:site_name`·홈 제목을 따른다. 배포 후 Search Console에서 홈 URL 색인 재요청을 한다.
- 파비콘은 `scripts/gen-favicon.mjs`가 로고에서 해 얼굴만 잘라 만든다(`favicon.ico` 16·32·48px, `favicon-48.png` 포함). Google은 48px 배수 파비콘을 권장한다.
- 2026-10-17 추가: 한국어 하위 페이지 제목에서 `| make your own day`를 뺐다. Google은 사이트 이름을 제목 위에 따로 보여 주므로 제목은 `[무료] 내일의 운세 — …`처럼 무료가 먼저 보이게 한다. 홈 제목은 사이트 이름 신호를 위해 `무료 사주 · 오늘의 운세 · 궁합 | make your own day`로 브랜드를 유지한다. 영어 페이지는 `| K-Fortune`을 유지한다.

## 2026-10-18 초기 노출 점검과 일별 결과 예시

한국 웹 검색에서 `/tomorrow/`는 6노출·평균 31.17위, `/year/2027/`은 2노출·77.5위, `/today/`는 1노출·18위였다. 검색어 표의 `내일의 운세`는 2노출·9위, `내일 일진`은 1노출·5위다. 검색어 표와 페이지 표는 별도 집계이며 실제 쿼리-페이지 쌍으로 결합하지 않았다. 차트 37노출·1클릭과 상세 표 13노출·0클릭 사이 차이의 원인은 미확인이다.

`/tomorrow/`의 Google 색인은 생성됨, Google 선택 canonical은 자기 주소, 최근 수집은 10월 17일이었다. 해당 수집본의 제목에는 무료가 없고 브랜드 꼬리가 남아 있었지만 10월 18일 실시간 검사에는 최신 `[무료]` 제목과 색인 가능 상태가 확인됐다. 수집 시점 차이를 배포 실패나 순위 하락 원인으로 단정하지 않는다.

오늘·내일 도구에는 입력 전 결과를 확인할 공개 예시가 없어 `src/site/public-examples.js`에서 기존 가상 입력과 실제 `day` 엔진을 재사용해 날짜·일진·종합 및 7개 분야 점수·총운·읽는 법을 제공한다. 한국어·영어 페이지 모두 같은 규칙을 쓰며, KST 날짜와 연말 경계를 검증한다. 예시는 이용자의 결과가 아니고 성공 확률도 아니라는 한계를 함께 표시한다. 첫 화면에는 예시로 이동하는 링크를 두고 예시 본문은 기존 공통 광고 뒤에 배치한다.

새 랜딩·날짜별 URL·가짜 리뷰·자격·예측 정확도는 추가하지 않는다. 기존 제목 변경을 유지하고 실제 배포일 이후 3~7일에 재수집 여부, 완결 데이터 약 28일 확보 후 동일 국가·기기·페이지·검색어 구성의 변화를 확인한다. 이는 운영상 관찰 간격이며 순위 상승을 보장하는 기간이 아니다.
- 2026-10-22 Search Console "리디렉션이 포함된 페이지": 모든 페이지 머리의 언어 전환 링크가 `?lang=ko`/`?lang=en`이라 서버가 302로 넘기고, 이 주소들이 색인 보고서에 쌓였다. 링크는 리디렉션 없는 실제 주소(`/today/`, `/en/today/`)로 바꾸고, 선택한 언어는 클릭할 때 쿠키로 저장한다. 서버의 `?lang=` 처리는 예전 링크를 위해 남겨 둔다. `tests/site.test.js`가 내부 링크에 리디렉션 주소가 없는지 확인한다.
