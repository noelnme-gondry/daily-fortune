# 광고 위치 A/B 실험

`ad_position_v1`은 결과가 있는 계산기에서 같은 쿠팡 배너의 위치만 비교한다.

| 그룹 | 위치 |
| --- | --- |
| A | 결과 공유 버튼과 안내문 바로 아래 |
| B | 결과 영역의 첫 요소. 자동 스크롤도 이 영역의 광고부터 시작 |

기존 모바일 레이아웃은 계산 후 결과를 입력 폼보다 위로 정렬한다. 이 정렬은 유지하고 결과 영역 내부의 광고 위치만 바꾼다. 배너 크기·발급 ID·추적 코드는 동일하며 광고 라벨과 수수료 고지도 함께 이동한다.

## 배정과 적용 범위

- 첫 방문에 50:50 무작위 배정하고 localStorage에 A/B 값만 저장한다. 이름·생년월일·사용자 식별자를 저장하지 않는다.
- 브라우저 저장이 불가능하면 sessionStorage, 그마저 불가능하면 현재 문서에서만 유지한다. `assignment_scope`는 각각 `browser`, `session`, `page`다.
- 실험 ID·저장 키·그룹별 위치는 `src/domain/ad-experiment.js`에서 관리한다. 쿠키나 사이트 데이터를 지우거나 다른 기기를 사용하면 배정이 달라질 수 있다.
- 일반 운세·궁합·만세력·캐릭터·랭킹·토정비결 계산기를 포함한다. 저장된 입력의 자동 결과 복원도 포함한다.
- 홈 입력 화면, 띠별 콘텐츠, 백과, 공유 카드, 404는 실험 대상에서 제외한다. 일반 콘텐츠의 기존 하단 광고는 유지한다.
- 계산 전 광고 영역 도달은 실험 지표에 넣지 않는다. 유효한 결과를 표시한 뒤 측정을 시작한다.

## 이벤트와 분석

| 이벤트 | 의미 |
| --- | --- |
| `ad_experiment_exposure` | 성공한 결과에 A/B 광고 위치를 적용함. 광고를 봤다는 뜻은 아님 |
| `ad_slot_view` | 활성 탭에서 광고 지면 50% 이상이 뷰포트에 들어옴 |
| `result_view` | 활성 탭에서 결과의 첫 제목 50% 이상이 뷰포트에 들어옴. 완독을 의미하지 않음 |
| `share` | 결과 공유 버튼 클릭. 공유 완료와 구분 |
| `calc_result` | 계산 완료. 기존 이벤트 유지 |

실험 진입·광고 도달·결과 도달은 문서 내 같은 경로당 각각 한 번만 기록한다. 재계산으로 중복되지 않으며 새 문서 이동·새로고침에서는 다시 기록한다. 계산·공유 이벤트는 기존 동작별 기록을 유지한다.

실험 대상 페이지의 이벤트에 `experiment_id`, `experiment_variant`, `ad_placement`, `assignment_scope`, `tool`을 함께 붙인다. GA4 관리 → 맞춤 정의에서 필요한 항목을 이벤트 범위 맞춤 측정기준으로 등록해야 탐색 보고서에서 그룹을 나눌 수 있다. 이 코드 변경만으로 GA4 관리 화면 설정을 대신하지는 않는다.

권장 비교 방법:

1. `experiment_id = ad_position_v1`과 `assignment_scope = browser`로 제한한다.
2. 실험 진입 사용자 중 광고 도달 사용자 비율, 결과 도달 사용자 비율, 공유 클릭 사용자 비율을 A/B별로 비교한다. 분자·분모 모두 사용자 기준을 사용하고, 반복 클릭 이벤트 수를 사용자 수로 나누지 않는다.
3. 모바일·데스크톱, 계산기 종류를 나눠 함께 확인한다. 모바일 메뉴 개선은 두 그룹에 동일하게 적용된다.
4. 관측 기간·최소 표본과 판단 기준은 트래픽과 기존 도달률을 보고 정한다. 이 구현만으로 통계적 유의성이나 수익 향상을 보장하지 않는다.

GA가 없거나 차단되면 기능은 동작하지만 이벤트를 수집할 수 없다. 광고 지면 도달은 쿠팡의 실제 광고 노출·클릭·구매 지표와 다르다. 같은 쿠팡 추적 코드를 유지하므로 이 실험만으로 그룹별 구매 수익을 분리하지 않는다.

## 검증과 수동 확인

브라우저 테스트는 실제 쿠팡 요청을 모의 처리하여 광고 실적을 발생시키지 않는다. A/B 위치, 최초 계산·재계산·저장 결과 복원, 모바일 자동 스크롤, 이벤트 중복 방지, 일반 페이지 제외, 저장소 제한을 검증한다.

개발자 도구에서 `src/domain/ad-experiment.js`의 저장 키에 A 또는 B를 넣고 새로고침하면 원하는 그룹을 확인할 수 있다. 운영 트래픽과 섞이지 않도록 로컬 환경에서 확인한다.

실험을 종료하고 기존 A로 돌아가려면 `src/client/main.js`의 `initAdExperiment()` 호출을 제거하고 재배포한다. 실험 배정이 없으면 공통 광고 배치가 A를 사용한다. 새 실험을 시작할 때는 ID와 저장 키의 버전을 함께 바꾼다.
