# Fortune 사주 콘텐츠 전체 주제 목록과 구현 기록

기준일: 2026-10-25 KST. 요청: 구글 관점에서 유용한 사주 콘텐츠를 목록화하고 현재 서비스에 추가. 신규 26편 + 기존 4편 = 30편의 KR/EN 가이드를 6개 분류로 연결했다. 기존 60일주·10일간·10십신·5오행·대표 신살·12운성·용어 사전·사주 보는 법은 재작성하지 않고 가이드에서 연결한다.

이 목록은 현재 서비스의 입력·결과 이해·생활 질문을 중심으로 합친 범위다. 모든 검색어를 열거했다거나 검색 수요를 검증했다는 뜻은 아니다. 구글이 지정한 필수 사주 주제·권장 글 수는 확인되지 않았다. 색인·순위·AdSense 승인 효과는 미확인이다.

## 선정 근거

- [Google 사용자 중심 콘텐츠 안내](https://developers.google.com/search/docs/fundamentals/creating-helpful-content?hl=ko): 독창적인 설명·정확성·작성 책임·만족스러운 경험. 단순 분량 증가나 정해진 글자 수를 목표로 하지 않는다.
- [Google 확장된 콘텐츠 악용 정책](https://developers.google.com/search/docs/essentials/spam-policies?hl=ko#scaled-content): 단어·날짜만 바꾼 저가치 페이지를 만들지 않는다. 동일 질문의 변형은 한 글에 묶었다.
- [한국민족문화대백과사전 사주](https://encykorea.aks.ac.kr/Article/E0025957): 전통 용어의 배경. 예측력 검증이나 서비스 점수식의 권위 근거로 삼지 않는다.
- 한국어 Google 개인화 검색 1개 질의와 입력·대운 경쟁 글 2편을 실제 열람했다. 시장 전체 순위·검색량·경쟁사 성과는 미확인이다.
- 현재 main에는 백과와 이용 가이드 4편이 있었으며, 개별 용어보다 입력·결과 비교·생활 질문을 연결하는 설명이 부족했다. 과거 2026-10-15 GSC 자료는 최신 성과로 재표기하지 않았다.

## 구현 계약

- 메타·경로·분류·질문·관련 글·계산기 링크는 READING_GUIDES에서 파생한다. 본문은 foundations·interpretation·everyday 모듈에 둔다.
- 신규 글은 구체적인 질문, 구별할 개념, 현재 서비스의 적용 범위, 실제 확인 순서, 3개 체크리스트와 관련 도구를 갖춘다.
- 원국·음력·입춘·밤 경계·오행·십신·지장간·강약·용신·대운·동일 입력의 11종 예시를 현재 엔진에서 생성한다. 예시 숫자를 전사하지 않는다.
- 신규 26편은 2026-10-25, 기존 4편은 2026-10-24 발행일을 유지한다. 변경된 가이드·백과 허브만 수정일을 올렸다.
- 건강·수명·임신·수익률·당첨률 같은 근거 없는 예측 수치를 추가하지 않는다. 전문 택일·작명·해외 시간대·진태양시·격국 판정을 지원하는 것처럼 표시하지 않는다.
- 기존 공용 셸·광고 제외·canonical·hreflang·사이트맵·RSS·llms 경로를 재사용한다. 홈에는 핵심 가이드 4편을 유지하고 전체 목록은 분류별로 탐색한다.
- 계산 엔진·골든값·저장 계약은 수정하지 않았다.

## 검증 중 발견한 테스트 기대값 수정

최초 전체 단위 검사에서 기존 경로 수 209를 고정한 테스트가 신규 26편 때문에 실패했다. 가이드 단일 목록의 길이를 사용해 기존 경로 수와 합산하도록 변경했다. 브라우저 검사에서는 신규 테스트 4개가 영어 전환 후 유지되는 #checklist 앵커를 누락해 실패했으며, 실제 제품 동작은 앵커 유지였다. 기대값에 앵커와 영어판 체크리스트 위치 검사를 추가했고 신규 흐름 5개를 다시 실행해 모두 통과했다. 실패 로그와 수정 후 로그를 별도로 보존한다. 현재 제품 동작을 잘못 바꾸거나 검사를 생략하지 않았다.
