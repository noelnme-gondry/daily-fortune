# 무료 토정비결 구현과 출처

## 범위

`/tojeong/`(올해)와 `/tojeong/{다음 연도}/`에서 생년월일로 144괘를 계산한다. 총운과 음력 12개월 한글 해설은 모두 무료이며, 생시·성별을 받지 않는다. 개인 입력은 브라우저에서만 계산하고 선택 시 IndexedDB `ohaeng-profiles/profiles`의 `tojeong` 키에 저장한다. 기존 사주 입력 `a`·`b`와 별개로 저장·삭제한다. 기존 사주 생일은 초기 입력으로 불러올 수 있다.

## 작괘 기준

- 계산법의 전거: [한국민족문화대백과사전 · 토정비결](https://encykorea.aks.ac.kr/Article/E0059207).
- 음양력과 음력 간지: 기존 의존성 `korean-lunar-calendar`. 사주 엔진의 절기 월주·입춘 연주를 사용하지 않는다.
- 세는나이: 보는 음력 연도 − 출생 음력 연도 + 1.
- 상괘: (세는나이 + 보는 해의 태세수) % 8. 0이면 8.
- 중괘: (보는 해의 음력 생월 날수 + 해당 월의 월건수) % 6. 0이면 6. 생월 **번호**를 더하는 방식이 아니다.
- 하괘: (보는 해에 적용한 음력 생일 + 해당 날의 일진수) % 3. 0이면 3.
- 수표와 계산 참고: [molpass/mcp-tojeong](https://github.com/molpass/mcp-tojeong/tree/d252dbfe9ad68a91665490f9800cefa86f90f07d), MIT. 소스의 선천수·중천수로 태세·월건·일진수를 구한다.
- 음력 생일이 윤달이면 평달에 대응시키고, 보는 해에 해당 월 30일이 없으면 29일을 사용한다. 이는 사이트에서 선택한 날짜 처리 관례이며 전통 판본 전체의 합의로 주장하지 않는다. 결과 화면에 조정 여부를 명시한다.
- 없는 출생 윤달과 날짜는 입력 오류다. 실제 출생일 검증 후에만 위 대응 규칙을 적용한다.
- 풀이 기간은 설날부터 다음 설날 전날이다. 윤달의 월별 해설은 같은 번호의 평달과 공유한다.
- 라이브러리 범위를 고려해 지원 연도는 1930~2049로 제한한다. 범위 밖에서는 계산 불가를 표시하며 임의 결과를 만들지 않는다. 전체 한 해가 지원되는 범위의 확대는 달력 자료 갱신 후 검증해야 한다.

## 144괘 해설

- 원본: `molpass/mcp-tojeong/data/tojeong_144.json`.
- 고정 커밋: `d252dbfe9ad68a91665490f9800cefa86f90f07d`.
- 로컬: `src/content/tojeong-144.json`. 내용 수정 없이 보관하고 표시할 때만 문단을 나눈다.
- 배포: 브라우저는 144괘 전체를 받지 않는다. 빌드 때 `vite.config.js`의 `tojeongData`가 괘별 파일(`/data/tojeong/{괘}.json`, 약 4.5KB)을 내보내고, 계산기는 자기 괘 하나만 받는다. 서버(공유 카드)는 `src/content/tojeong-readings.js`로 원본을 읽는다.
- 주소: 올해는 `/tojeong/` 하나만 두고 `/tojeong/{올해}/`는 301로 보낸다. 내년은 `/tojeong/{내년}/`. 각 페이지에는 그해의 태세수·음력 월별 날수·월건수·중괘와 출생 연도별 상괘를 정리한 작괘 기준표를 싣는다.
- SHA-256: `d92d0e984e6a30450a7a7e14191e9fdd425440f2e8c80b91f211d84cf923ccdd`.
- 제공자는 1998년 개인 소장 자료를 현대 맞춤법으로 윤문한 한글 해설이라고 밝히고 MIT로 공개했다. Copyright © 2026 Lee, JungHoon. 라이선스 전문은 `public/licenses/mcp-tojeong.txt`에 포함하며 페이지와 결과에서 링크한다.
- 고서 한문 원전이나 오행 운세의 자체 번역으로 표시하지 않는다. 판본별 차이와 길흉 표현의 성격을 화면에 안내한다. 고서와의 144괘 전수 대조는 미실시다.
- 원자료의 서지 정보와 전문가 감수 이력은 미확인이다. MIT 공개 사실을 공인·검수 또는 원문 정확성의 근거로 삼지 않는다. 계산식의 전거 확인과 구현 테스트는 해설 내용의 독립 검증이 아니다.
- 외부 MCP 서버를 연결·설치하지 않는다. 고정한 데이터와 자체 계산 모듈을 배포하며, 이용자의 입력을 자료 제공자에게 전송하거나 그 저장소의 변경을 자동 반영하지 않는다.
- 총운 144개, 월별 해설 1,728개를 사용한다. 임의 점수·확률·가상 인물 결과를 덧붙이지 않는다. 좋은 내용과 나쁜 내용을 함께 유지한다.
- 큰 해설 데이터는 토정비결 페이지에서만 지연 로드되는 청크에 포함한다.

## 검증 계약

공개 작괘 예시(음력 1976-08-26, 2005년 → 212), 대월/소월 구분(음력 1975-07-25, 2024년 → 811), 나머지 0, 음양력 동등성, 음력 출생 연도 경계, 윤달·말일 보정, 불가능한 입력, 144괘 데이터 완전성을 검증한다. 브라우저에서는 홈 진입, 월 선택, 연도 이동과 복원, 독립 저장·삭제, 저장 실패, 320~1440px 화면 폭을 확인한다. 기존 사주 엔진의 골든값은 변경하지 않는다.

페이지는 기존 한국어 공용 셸·canonical·FAQ JSON-LD·무료 가격 정보·내부 메뉴·sitemap·llms 요약에 연결한다. 현재 사이트는 한국어 단일 언어로, 별도 영어 라우트나 hreflang은 만들지 않는다.
