# 띠별 운세를 생활 중심으로 설명하기

## 문제와 변경

일간·월간 본문은 행동 예시 뒤에 지지·천간·합충·오행의 정의를 이어 붙이고 있었다. 연간은 분야별 점수가 이미 있는데도 총운에서 그 차이를 설명하지 않았다.

- 일간·월간: 실제 관계·오행에 연결되는 대인·협업·재물·학업·업무의 활용 방향과 이동·관계·업무의 주의점을 일상 언어로 설명한다. 전체 점수가 60점 미만이면 먼저 속도 조절을 권하고, 부분적인 강점을 전체 운이 좋다는 뜻으로 확대하지 않는다.
- 일간 상세: 운의 방향, 활용 행동, 함께 챙길 점을 나누어 표시한다. 계산 근거는 기본적으로 닫힌 네이티브 `details`에 보존하며 키보드로 열 수 있다. 별도로 계산하지 않은 일간 분야 점수는 만들지 않는다.
- 연간: 실제 다섯 분야의 최고·최저 점수와 모든 동점 분야를 총운에서 설명한다. 모두 같으면 특정 분야를 최고로 고르지 않으며, 최저 점수도 60점 이상이면 나쁜 운이라고 하지 않는다. 분야별 해설도 해당 점수대에 맞게 활용 방향을 설명한다.
- 연간 화면: 총운과 분야별 해설을 앞에 배치한다. 기술적인 관계·삼재 정보는 펼침 영역으로 옮기고, 좋은 달·조심할 달·행운 정보는 계속 바로 표시한다.
- 월간 카드: 생활 해설이 먼저 나오고, 월주와 관계 이름은 카드 아래에서 펼쳐 볼 수 있다. 출생 연도 선택 후에도 같은 렌더러를 사용한다.
- 한국어·영어를 함께 적용했다. 점수 산식·가중치·행운값·출생 연도별 조정은 변경하지 않았다. 앞선 504개 제목 확장 작업도 보존했다.

## 예시

2026년 쥐띠는 종합 54점, 분야별 직장 50·금전 62·연애 54·이동 72·건강 48점이다. 총운은 이제 이동운 72점을 활용할 부분으로, 건강운 48점을 일정을 덜고 휴식을 확보할 부분으로 설명한다. 종합이 낮다는 이유로 모든 분야를 나쁘게 쓰거나, 이동운이 높다고 전체가 좋다고 쓰지 않는다.

2026-10-20 소띠 일간은 57점이다. 조언을 구하고 막힌 부분을 배우는 학업·업무의 활용 방향을 설명하면서, 맡은 책임과 마감을 관리하고 새 일을 늘리기 전에 여력을 확인하도록 안내한다.

## 검증 범위

- `tests/zodiac-outlook.test.js`: 12띠·60일, 12개월, 2026~2027년의 용어 없는 생활 설명, 실제 분야 점수·동점·낮은 점수 처리, 한영 대응과 결정성. 연결 전 3개 실패를 확인한 뒤 연결 후 통과했다.
- 기존 `tests/reading-variety.test.js`: 점수 골든 해시, 같은 날짜 본문 중복 방지, 60일 뒤 행동 순환, 월간의 일간 표현 혼입 방지, 한영 공유 링크 호환성을 유지했다. 행동을 첫 문장 대신 별도 `advice` 필드에서 검증하도록 바꿨다.
- 기존 `tests/headline-variety.test.js`: 제목 504개와 장기간 다양성 검증을 유지한다.
- 브라우저 검증: 일간 목록·모달·직접 진입, 근거 영역의 초기 접힘과 키보드 열기, 한영 320px 화면, 출생 연도 선택 후 월별 본문.
- `tests/browser/zodiac-outlook.spec.js`: 자바스크립트를 끈 한영 320px 화면에서 연간 총운·분야 점수·월별 본문과 내일의 운세를 확인하고, 근거를 키보드로 펼친다.

최종 결과: `npm run test:all` 216개 통과(단위·사이트 119개 + 브라우저 97개), 이후 추가한 무자바스크립트 브라우저 테스트 2개도 통과해 총 218개를 확인했다. `npm run lint`, `npm run build`, `git diff --check` 통과. 빌드는 한영 404개 페이지를 생성했다. 기존 도구 청크의 500 kB 초과 경고는 남으며, 앞선 제목 확장 이후의 568.67 kB(gzip 179.61 kB)에서 증가하지 않았다.

해설은 기존 운세 규칙을 생활 언어로 옮긴 것이며 현실 사건의 확률을 새로 계산한 것이 아니다. 운영 배포 및 실제 외부 웹폰트의 육안 검증은 수행하지 않는다.
