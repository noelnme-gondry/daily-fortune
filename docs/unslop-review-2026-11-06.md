# Fortune unslop 적용 및 화면 점검

본문·하단·계산 후 상태와 다른 브라우저까지 확대한 결과는 [추가 화면 검수와 수정](unslop-followup-2026-11-06.md)에 기록했습니다. 아래 내용은 최초 적용 범위의 기록입니다.

브랜치·커밋·배포 상태는 머지 전 로컬 검수 당시 기준입니다.

2026년 11월 6일 한국 시간 기준으로 UI 개선 스킬 [unslop](https://github.com/heydamir/unslop)을 적용했습니다. 기존 해 로고, 쪽빛, 서체와 캐릭터 그림에 제품의 특징이 있어 부분 다듬기를 선택했습니다. 수정과 검증은 로컬의 `codex/unslop-site-review` 브랜치에서 끝났으며 운영 배포는 수행하지 않았습니다.

## 디자인 방향

- 제품: 생년월일로 운세와 사주를 읽고 두 사람의 해석을 비교하는 도구입니다.
- 성격: 차분함, 친근함, 명료함을 기준으로 삼았습니다.
- 바탕: 현재의 종이 지면과 쪽빛을 유지했습니다.
- 주요 볼거리: 실제 계산 결과와 인생 캐릭터 그림에 색과 디테일을 남겼습니다.
- 고유 요소: 해 로고와 오행을 구분하는 명식표를 유지했습니다.

## 확인한 문제와 적용 결과

| 위치 | 확인한 문제 | 적용 결과 |
| --- | --- | --- |

## unslop의 아홉 단계별 판단

| 단계 | 적용 범위 |
| --- | --- |
| 간격 | 공통 지면, 홈, 입력 폼, 안내 링크, 결과 설정, 캐릭터 카드의 확인된 간격을 정리했습니다. |
| 색 | 보조 선택 면의 강조를 줄이고 다크 모드 등급의 글자 대비를 수정했습니다. 오행의 의미를 나타내는 색은 유지했습니다. |
| 아이콘 | 기존 Lucide 아이콘과 브랜드 아이콘의 공통 정의를 유지했습니다. 띠와 캐릭터 그림은 제품 콘텐츠로 보존했습니다. |
| 문구 | 캐릭터 장 표기를 언어에 맞췄습니다. 운세 해설과 계산의 의미는 유지했습니다. |
| 서체 | 기존 서체를 유지하며 제목의 굵기와 작은 설명 글자를 조정했습니다. |
| 배치 | 공통 셸, 섹션 순서, 입력과 결과의 진입 경로를 유지했습니다. |
| 세부 요소 | 주요 조작 높이와 등급 글자색을 정리하고 선택 상태의 밑줄 및 키보드 포커스를 유지했습니다. |
| 시각 자료 | 기존 해 로고, 캐릭터, 띠 그림과 계산 차트를 사용했습니다. 새 이미지 생성은 필요하지 않았습니다. |
| 동작 | 블록별 등장 효과와 카드의 위치 이동을 줄였습니다. 동작 줄이기 설정과 키보드 상세 열기 및 복귀를 검증했습니다. |

## 검증 결과

- `npm run test:all`: 단위 및 사이트 테스트 166개와 브라우저 테스트 190개, 총 356개 통과.
- `npm run lint`: 통과. 새 테스트에서 발견한 브라우저 전역 참조 표기를 수정한 뒤 재실행했습니다.
- `npm run build`: 470페이지와 검색 수집 파일 생성 통과.
- `git diff --check`: 통과.
- 추가 회귀 검증 6개: 한국어와 영어의 밝은 화면 및 어두운 화면 등급 대비, 320px 캐릭터 설명의 최소 크기와 가로 잘림, 동작 줄이기, Enter로 상세 열기와 Escape 후 포커스 복귀를 확인했습니다.
- 수정 전에는 다크 모드 대비와 모바일 글자 크기로 4개가 실패했고 수정 후에는 6개가 모두 통과했습니다.
- 빌드된 운영용 앱의 한국어 및 영어 흐름: 홈 입력 제출, 오늘의 운세 7개 분야, 저장 복원, 캐릭터 상세의 키보드 조작, 랭킹 결과를 확인했습니다. 브라우저 실행 오류는 없었습니다.

### 전체 경로와 화면 폭

470개 정적 경로를 Chromium의 320px 폭에서 검사했습니다. 아래 대표 25개 경로에는 한국어와 영어, 밝은 화면과 어두운 화면, 320px·768px·1024px·1440px 폭을 조합한 400회를 추가했습니다. 총 870회 검사에서 문서 가로 넘침, main의 h1 누락 또는 중복, aria-controls 대상 누락 또는 중복이 없었으며 브라우저 실행 오류도 없었습니다.

육안 확인은 홈, 오늘 결과, 인생 캐릭터의 대표 화면을 대상으로 했습니다. 자동 화면 검사는 외부 요청을 차단했으므로 외부 글꼴이 실제로 표시된 모든 화면과 운영 광고의 송출 결과는 별도 확인 범위입니다. 추가한 Hahmlet 600을 포함한 Google Fonts 스타일시트의 HTTP 응답은 정상 확인했습니다. 이 검증은 사이트 전체의 접근성 인증이나 모든 외부 서비스 상태를 보장하지 않습니다.

## 주요 파일과 보존 상태

- `src/styles/main.css`: 공통 간격, 선택 상태, 대비, 글자 크기, 동작.
- `src/site/layout.js`: Hahmlet 600 굵기 요청.
- `src/client/story-view.js`: 한국어 및 영어 장 표기.
- `tests/browser/design-polish.spec.js`: 대비와 모바일 캐릭터의 회귀 검증.

계산 엔진과 골든값, 라우트와 도구 ID, 공유 및 측정 계약은 변경하지 않았습니다. `.agents/`와 `.legacy-local/`은 수정하지 않았습니다.

최종 fetch 기준 `origin/main`과 HEAD의 커밋 차이는 앞섬 0개, 뒤처짐 0개입니다. 기준 커밋은 `2e703726fa9a27b3d118bc394600734588fb69b1`이며 변경은 미커밋 상태입니다. 커밋, push, PR 생성, 운영 배포는 수행하지 않았습니다.

기존 `.gitignore` 수정과 `docs/character-downfall-preview.png` 삭제 상태를 그대로 보존했습니다. 기존 미추적 파일인 `AGENTS.md`, `START_HERE.txt`, `Creative/`, `output/`, `videos/`, 이전 랜딩 문서와 검색 조사 자료도 유지했습니다.

## 후속 확인

처음 방문한 사용자의 모바일 입력 폼은 여전히 길어 주요 계산 버튼이 첫 화면 아래에 있습니다. 이번에는 기존 입력 순서를 유지했으며, 선택 이름 입력의 위치나 안내 접기는 별도의 사용성 변경으로 검토할 수 있습니다. 실제 이용률이나 전환율 개선 여부는 이번 화면 점검만으로 판단할 수 없습니다.

현재 수정본은 로컬 미리보기에서 확인할 수 있습니다. 운영 화면 반영과 실제 광고 및 외부 글꼴의 육안 확인은 남아 있습니다.
