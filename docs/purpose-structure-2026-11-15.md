# 목적별 구조와 풀이 개선

## 구조

- 공통 헤더·전체 메뉴·홈·푸터는 날짜별 운세 / 내 사주 이해 / 두 사람의 궁합 / 재미로 보는 사주 / 사주 읽는 법의 다섯 분류를 공유한다.
- 홈 첫 화면은 짧은 소개, 실제 출생 입력, 캐릭터·랭킹의 두 큰 카드로 구성한다. 띠·연간 운세 전체 목록과 날짜 상자의 반복 노출을 줄이고 각 목적의 실제 경로로 연결한다.
- 기간 링크는 기존 세션 입력을 이어 쓰는 실제 경로를 사용한다. 원국과 분야별 본문은 펼친 상태이고 공유·후속 풀이·상징색 광고는 주요 풀이 뒤에 둔다.
- 설명은 짧은 용어 도움말과 항목별 대화상자로 나눈다. 강약·용신·대운의 원래 수식·가중치·구간을 보존하고 각각 해당 결과에서 열어 본다. 노션 방식의 본문 아코디언은 제거한다.
- 랭킹은 분포 그래프와 공개 동작을 유지한다. 일곱 항목의 평균 대비 차이와 실제 원국에서 집계된 요소를 별도로 보여주며, 실제 사람의 통계와 이론상 조합을 혼동하지 않는다.
- 본문과 제목은 따뜻한 배경 위에 충분히 진한 색을 쓴다. Gowun Dodum / Gowun Batang과 시스템 대체 서체를 사용한다. 좁은 문단 폭과 강제 균등 줄바꿈을 줄이고, 목적별 링크의 짧은 이름은 하나의 조작 단위로 유지한다.

## 풀이 편집

2026-11-16 KST 내부 브라우저에서 [네이버 오늘의 운세](https://search.naver.com/search.naver?query=%EC%98%A4%EB%8A%98%EC%9D%98%20%EC%9A%B4%EC%84%B8)를 예시 입력(1990-05-15, 양력, 남성, 시간 모름)으로 확인했다. 오늘·내일·주·월과 분야 선택이 구분되어 있고, 제공처는 포춘82로 표시된다. 직장운을 포함한 결과의 설명 구조를 참고했으며 문구나 비공개 계산식을 복제하지 않았다. 네이버의 사주 계산과 같은 결과임을 검증했다는 뜻은 아니다.

용어의 기본 범위는 [한국민족문화대백과사전의 사주 항목](https://encykorea.aks.ac.kr/Article/E0025957)을 함께 확인했다. 사주를 세우는 역법과 그에 대한 해석을 구분하며, 자시·시간 보정 등 방식에 따라 차이가 생길 수 있음을 유지한다.

문제였던 직장운의 협업·확인 조언은 `reading-editorial.js`에서 용어의 뜻, 실제 반영된 요인, 업무에서 읽는 양면으로 편집한다. 예를 들어 비견은 동등한 전문성을 보태는 협업과 주도권 경쟁을 함께 설명한다. 월지합은 사회 활동 자리의 연결이라는 뜻과 해당 모델의 가점임을 설명한다. 특정 인물의 등장·배신·승진·이직을 보장하지 않는다. 실제 일진 근거가 있으면 그 근거를 분야 본문에서 먼저 보여주고, 없으면 기존 점수대 해설로 대체한다.

계산 엔진·가중치·순위표·골든값은 수정하지 않았다. 수정 전후 24개 입력의 원국·일·주·월·년·평생·랭킹 수치와 불리언 값 168건을 비교해 일치를 확인했다.

## 검증 기록

- 로컬 단위 테스트 179개 통과, lint 통과, 470개 페이지 프로덕션 빌드 및 릴리스 자산 검증 통과.
- 470개 페이지 전체의 내부 경로·앵커·ARIA 제어 대상·중복 ID·단일 h1 정적 검사에서 오류 0건.
- 현재 자산을 release:prepare로 등록하고 이전 보존 자산은 유지했다.
- 로컬 `npm run test:all`은 단위 단계에서 실패한 옛 UI 계약을 수정한 뒤 단위 검증을 재실행했다. 브라우저 서버의 127.0.0.1:4176 수신은 환경의 EPERM으로 실행할 수 없어 CI에서 이어 검증한다.
- `purpose-layout.spec.js`는 주요 20개 경로, KR/EN, light/dark, 320·390·768·1440 너비에서 가로 넘침·메뉴 폭·핵심 글자 대비·메뉴 포커스·그래프를 검사하고 주요 결과 화면을 기록한다. 기존 계산·저장·공유·날짜 이동 시나리오도 유지한다.
- `reading_detail_open`은 결과 안의 설명 창에만 연결해 기존 결과 상세 이벤트의 범위를 유지한다. FAQ는 개별 접기 없이 읽으므로 과거 `faq_open` 횟수를 새 배치와 직접 비교하지 않는다.
- 첫 CI에서 브라우저 223건 중 211건이 통과했다. 실패한 12건을 확인해 모바일 헤더·첫 화면 높이·중복 수정 버튼·설명 창 포커스를 고치고 변경된 구조에 맞게 이전 검사 대상을 수정했다. 터치 설명창 회귀 검사를 추가해 최종 CI는 224건으로 재검증한다.
- 최종 CI 결과와 발견된 수정은 PR에 기록한다. 브라우저 검증이 끝나기 전에는 모바일 시각 검토 완료로 보고하지 않는다.

기존 관리 폴더의 미추적 시안·Creative·output·videos·Archive와 사용자 변경은 건드리지 않고 별도 codex 브랜치에서 작업한다.
