# 2026-11-14 사이트 진단 반영

사용자가 제공한 `site-critique-2026-11-14.md`의 로컬 진단을 현행 코드와 대조했다. 문서의 수치를 운영 전환율로 해석하지 않았으며, 계산 엔진·점수 산식·골든값은 변경하지 않았다.

## 반영한 수정

| 진단 | 반영 내용 |
| --- | --- |
| 시각 공란 제출 실패 | 정확한 시각이 비어 있으면 시간 미상으로 정규화한다. 결과에 시주 제외 안내와 입력 수정 버튼을 제공한다. 시간 모름·시진 선택·기존 저장 입력 계약은 유지한다. |
| 남성 자동 선택 | 성별 기본값을 없애고 명시적으로 받는다. 미선택 오류는 성별 필드의 ARIA 오류 연결과 포커스로 안내한다. 새 사람 입력에서도 이전 성별을 남기지 않는다. |
| 오류·제출 계측 불명확 | 검증 전 `calc_attempt`, 검증 후 `calc_submit`, 직접 계산 성공 `calc_complete`를 구분한다. `calc_result`는 자동 복원까지 포함한다. 오류에는 입력값 대신 `error_field`만 추가한다. 토정비결에도 같은 단계 의미를 적용한다. |
| 계산기 랜딩 폼이 아래에 있음 | 소개를 첫 문장으로 줄이고 전체 소개는 계산 안내에 보존한다. 날짜 상자와 예시 링크를 폼 뒤로 옮긴다. 오늘 운세의 개인·띠별 선택은 짧은 링크로 바꾼다. 단일 폼의 이름·시간 보정 안내는 제출 버튼 뒤로 보낸다. |

| 긴 일간 상세 | 오늘·내일의 일곱 분야를 제목·점수·흐름 미리보기로 접는다. 칩·해시 진입은 해당 상세를 먼저 열고 포커스를 옮긴다. 근거는 별도 펼침을 유지한다. |
| 광고가 상세보다 먼저 나옴 | 행운색 배너를 주요 해설 뒤로 이동한다. SDK 실패로 `unavailable`인 지면은 고지를 포함해 접는다. 쿠팡 설정의 `tsource`는 개인 정보 없이 공통·행운색·도구별로 구분한다. |
| 개인 결과와 공개 예시 혼동 | 개인 결과가 있을 때 공개 예시를 숨기고, 입력 오류로 결과를 지우면 예시를 다시 제공한다. 모바일 폼은 결과 뒤에서 숨기며 수정 버튼으로 연다. PC는 옆의 편집 폼을 유지한다. |
| 공유 출처 누락 | 카카오·복사·X·Facebook·기기 공유에 채널별 UTM을 붙인다. 공유 카드의 요약 쿼리·언어·날짜는 유지하고, UTM에는 이름·점수·생일을 넣지 않는다. |
| 재방문·콘텐츠 소비 계측 누락 | 결과에서 기기 저장, 저장 선택·성공, 사람 추가·수정·선택, 분야 선택, 상세 열기, 순위 공개, 캐릭터 상세, 결과 섹션 도달을 계측한다. 이름·프로필 ID·순위·점수·캐릭터 ID는 전송하지 않는다. |

| 초점·헤더·서체 | 자동 초점이 가는 요약의 전체 테두리를 제거하며 조작 요소의 키보드 초점은 유지한다. 저장한 사람 메뉴 줄바꿈을 막고 언어 전환을 44px로 높인다. 본문을 시스템 서체로 바꿔 외부 한글 서체는 두 종류만 요청한다. |
| 분석 문서 불일치 | 실제 `calc_origin` 값과 공유 후속 이벤트를 README에 맞춘다. 새 퍼널은 `measurement_version=3`으로 구분하고 GA 맞춤 정의·과거 수정 규칙 점검은 TODO에 남긴다. |

## 운영에서 확인해야 하는 항목

- GA4 맞춤 정의 등록, `calc_result → fortune_view` 수정 규칙, 핵심 이벤트 설정, 운영 전환율·유입 채널은 미확인이다. 코드가 전송하는 이름은 `calc_result`다.
- Railway의 `VITE_KAKAO_JS_KEY`와 카카오 플랫폼 도메인 등록은 미확인이다. 임의 키를 만들거나 공유 버튼을 강제로 노출하지 않았다.
- 쿠팡 실제 송출·클릭·수익 및 `tsource`의 운영 리포트 반영은 미확인이다. 테스트는 외부 실적을 만들지 않는 SDK 대역과 차단 환경으로 검증한다.
- 운영 CMP·GA4 Consent Mode 연동 상태는 미확인이다. 운영 계정에서 확인할 항목을 TODO에 기록했다.
- 로컬 광고 차단 환경의 레이아웃 검증으로 운영 CLS·실사용 성능을 단정할 수 없다.

## 후속 실험으로 남긴 제안

공유 랜딩의 인라인 생일 입력, 출석·연속 방문, 결과 썸네일 신설, 계산 엔진을 첫 입력 시점에만 로드하는 구조 변경은 이번 수정에 포함하지 않았다. 각각 진입 계약·개인정보 안내·유저 행동·초기 로딩과 첫 계산 지연을 함께 비교해야 하는 별도 작업이다. 상세 도구의 보조 옵션 전체 재구성, 모든 작은 링크·태그의 터치 영역, 다크 모드 버튼 색 변경도 별도 시각 검토 대상으로 남겼다.
