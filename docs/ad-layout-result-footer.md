# 결과 하단 공통 배너

공통 쿠팡 배너를 결과 전체 뒤로 옮긴다. 상단의 행운색 소품 배너와 붙어 보이는 문제를 줄이고 PC에서는 입력 폼과 결과를 합친 너비, 모바일에서는 좌우 여백을 제외한 너비를 사용한다. 화면에 고정하거나 본문 위에 겹치지 않는다.

- 공통 지면: 너비 100%, 높이 250px. 결과 아래 최대 1,128px, 일반 콘텐츠 하단 최대 1,408px.
- 기존 배너 ID와 공식 SDK 연결은 유지한다. 실제 상품 구성·개수는 쿠팡이 정한다.
- 공통 배너를 계산기 전체의 형제로 유지해 고정 입력 폼이 배너를 가리지 않게 한다. 재계산은 iframe을 다시 삽입하지 않으며, 계산 오류로 결과를 비우면 배너를 본문 뒤로 돌려놓는다.
- PC 오른쪽 결과 열의 행운색 소품 배너는 현재 위치에서 높이를 250px에서 320px로 키운다. 모바일에도 높이 320px와 화면에 맞춘 너비를 적용한다. 별도 사이드바를 새로 만들지 않는다.

## 측정

계산기 이벤트는 `ad_layout_version=result_footer_v1`, `ad_placement=after_reading`으로 구분한다. 과거 `ad_position_v2` 신규 배정과 `ad_experiment_exposure` 전송은 중단하고 기존 브라우저 저장값은 건드리지 않는다. 과거 실험 문서는 이전 자료 해석용이다.

`ad_slot_view`의 공통 배너는 `ad_slot=common`, `ad_context=result_footer`로 측정한다. 행운색 배너는 `ad_slot=lucky`, `ad_context=result`, 일반 콘텐츠는 `ad_context=content`를 유지한다. 활성 탭에서 슬롯 50% 이상이 보일 때 문서의 경로·슬롯별 한 번 전송한다. 계산기는 성공 결과 이후부터 측정한다. 도달은 실제 광고 송출이나 클릭이 아니며 iframe의 클릭을 추정하지 않는다.

`ad_layout_version`을 GA4 탐색에서 사용하려면 이벤트 범위 맞춤 측정기준 등록이 별도로 필요하다. 이 변경은 계정 등록이나 실제 수신을 확인한 것으로 간주하지 않는다. `ad_context`, `ad_placement`의 기존 맞춤 정의로도 새 위치를 구분할 수 있다.

## 검증 범위

브라우저 테스트는 외부 요청을 차단하고 쿠팡 SDK를 대체해 요청 크기·위치·한 개 유지·모바일 넘침·측정 조건을 확인한다. 실제 쿠팡 상품 렌더링은 내부 브라우저에서 별도로 확인한다. 구현이나 테스트 통과를 배포·클릭 증가의 증거로 사용하지 않는다.
