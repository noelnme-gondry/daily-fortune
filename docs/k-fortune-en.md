# K-Fortune 영어판

- 한국어 경로는 그대로 유지하고, 같은 경로의 `/en/` 버전을 제공합니다. 영어 브랜드는 `K-Fortune`입니다.
- 운영 Express 서버와 개발 Vite 서버는 `Accept-Language`의 우선 언어가 한국어가 아닐 때 해당 영어 경로로 302 이동합니다. 국가·IP 위치는 사용하지 않습니다.
- 헤더의 한국어/English 선택은 `fortune-language` 쿠키에 1년간 저장되며 자동 판정보다 우선합니다. `/en/` 직접 링크는 브라우저 언어와 무관하게 영어로 열립니다. 쿼리와 공유 결과는 언어 전환 때 유지합니다.
- 언어별 canonical·hreflang·JSON-LD·공유 이미지·설치 manifest와 전체 sitemap을 제공합니다. 검색 봇은 자동 이동시키지 않습니다.
- 자동 이동은 서버 기능입니다. `dist`만 별도 정적 호스팅에 올리는 경우 언어별 페이지와 수동 선택은 제공되지만, 자동 이동에는 호스팅의 언어 라우팅 설정이 필요합니다.

## 계산·데이터

계산식, 내부 식별자, 점수 분포표, 한국어 토정비결 원문은 그대로입니다. 영어판도 기존 한국 시간·역사적 표준시·서머타임 기준을 사용합니다. 해외 출생지의 시간대 변환은 추가하지 않았으며 입력 안내에 이 제한을 명시합니다.

토정비결 영어 데이터는 `src/content/tojeong-144.en.json`에 있습니다. 144괘 각각의 총운과 12개월 해설을 담고, 브라우저에는 자신의 괘 하나만 `/data/tojeong/en/{code}.json`으로 전송합니다. 원문에 있는 상충하거나 불명확한 표현은 임의로 고치지 않고 필요한 경우 번역문에 표시했습니다. 전통 문헌의 서술이며 실제 사건의 예측이나 보장은 아닙니다.

## 유지보수

- 언어 범위는 `src/i18n/runtime.js`에서 동기적으로 적용합니다. 서버 렌더에 비동기 작업을 넣지 않습니다.
- 공통 용어는 `src/i18n/terms.js`, 화면 문구는 `src/content/en/` 및 각 콘텐츠의 `.en.js`에서 관리합니다. 한국어 내부 key나 공유 캐릭터 ID를 번역하지 않습니다.
- 승인된 기존 로고를 이용한 영어 공유 이미지·manifest 재생성: `node scripts/gen-english-brand.mjs`.
- 검증: `npm run test:all`, `npm run lint`, `npm run build`. 영어 브라우저 진입과 계산·공유·수동 선택·궁합 worker는 `tests/browser/english.spec.js`에서 확인합니다.
